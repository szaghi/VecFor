# 10. Printing and files

`probe` writes its vertices: on the screen, into a binary file and a text file, into a stream file from which it reads
one vector straight away, and past its end, to see the error.

## Printing

`call v%printf` writes one line on standard output: the `prefix` (empty by default), the three components separated by
`sep` (`', '` by default), then the `suffix` (empty). Each number has the shortest digits that read back as the same
value. `unit=` sends the line to another unit, an open file or standard error (see
[Printing a vector](../cookbook#printing-a-vector)).

## Saving and loading

`call v%save_into_file(unit=u)` writes the three components to the unit `u`, open by you; `call
v%load_from_file(unit=u)` reads them back. Both write or read one record of three numbers, in the form of the unit:

- **unformatted**: the exact bits, 24 bytes per double precision vector; what is read back is equal to what was
  written, `r == p`.
- **formatted**, with `fmt=`, a format for three reals such as `'(3F6.2)'`: a text file, readable and portable, which
  keeps only the digits of the format. `fmt` is a format string; `'*'` (list-directed) is not supported.

## Stream files and positions

On a unit opened with `access='stream'`, `pos=` is the position, in file storage units (bytes, with gfortran), at which
the vector is written or read. `o%iolen()` (or `iolen(o)`) is the number of storage units of one vector, the value of
`inquire(iolength=)`: 24 for double precision. The third vector starts at `2 * 24 + 1`, and is read without reading the
two before it. `pos` is an `integer(I8P)` (64 bits), hence the `int(..., int64)`. For a direct access file, `iolen` is
the record length, `recl=` (see [A direct access file of vectors](../cookbook#a-direct-access-file-of-vectors)).

## Errors

All three procedures take the optional `iostat` and `iomsg` of Fortran I/O, and with them the status and the message
come back: reading past the end of the file gives `iostat = -1`, `End of file`; a malformed number in a text file
gives a positive status (see [An I/O error caught](../cookbook#an-i-o-error-caught)).

::: warning Always pass iostat
Unlike a plain `read` or `write`, these procedures **never stop the program** on an error: without `iostat`, a failed
read or write is silently ignored, and the vector keeps the value it had. Pass `iostat` and check it.
:::
